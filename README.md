# Web-приложение для симуляции отношений агентов на рынке недвижимости

## Описание проекта
Проект представляет собой интерактивное web-приложение, моделирующее поведение участников рынка недвижимости — покупателей, продавцов и застройщиков.  
Цель симуляции — показать, как изменение макроэкономических факторов (ставка, доходы, темпы строительства и др.) влияет на динамику цен и объём сделок.

Модель основана на базовых принципах микроэкономики и рыночного равновесия между спросом и предложением.  
Пользователь управляет параметрами среды, наблюдая, как рынок реагирует в реальном времени через интерактивные графики.

---

## Основные возможности
- Настройка ключевых факторов:
  - Процентная ставка (ставка ЦБ / ипотечная)
  - Рост доходов населения
  - Темпы строительства
  - Безработица
  - Государственные субсидии
  - Демографический рост
- Визуализация изменений:
  - Средняя цена недвижимости
  - Спрос и предложение
  - Точка рыночного равновесия
- Пошаговая симуляция (по периодам)
- Комментарии к результатам в реальном времени

---

## Техническая реализация

### Стек технологий
- **Frontend:** HTML5, CSS3, JavaScript
- **Графики:** Chart.js
- **Backend:** Node.js
- **Хранение данных:** JSON
