# Симулятор рынка недвижимости

Учебное веб-приложение на чистом HTML, CSS и JavaScript. Проект моделирует упрощённый рынок недвижимости: игрок строит и развивает объекты, следит за капиталом, спросом, репутацией, ставкой, кредитом и случайными событиями рынка.

Приложение не использует React, TypeScript, backend, базы данных, npm-зависимости, сборщики и фреймворки. Запуск выполняется обычным открытием файла `app/index.html` в браузере.

## Запуск

1. Открыть папку проекта.
2. Перейти в папку `app`.
3. Открыть `index.html` двойным кликом или через браузер.

```text
app/index.html
```

## Суть игры

Игрок управляет инвестиционным портфелем в течение 20 кварталов. За один квартал можно выполнить только одно действие:

- построить жильё
- построить офис
- построить ритейл
- улучшить выбранный объект
- продать выбранный объект
- взять кредит
- пропустить ход

После действия квартал автоматически завершается: начисляются доходы и расходы, списывается платёж по кредиту, происходит случайное событие, обновляется рынок и состояние сохраняется в `LocalStorage`.

## Текущее состояние интерфейса

Игра сделана как одностраничный сайт:

- стартовый экран с описанием проекта
- основной игровой экран
- компактная панель метрик сверху
- левый центр решений с действиями и советчиком
- большая городская карта справа
- карточки портфеля, события, сводка и графики ниже
- модальное окно завершения игры
- блоки правил и описания проекта

Карта реализована вручную на `canvas`. Внешние 3D-модели, изображения и библиотеки не используются. Здания, дороги, участки, машины, деревья, фонари и декоративные элементы рисуются процедурно средствами JavaScript Canvas API.

## Игровые параметры

Стартовые значения:

- деньги: `1 000 000`
- репутация: `50`
- спрос: `50`
- ставка: `10`
- квартал: `1`
- суммарная прибыль: `0`
- объектов: `0`
- кредита нет

Типы недвижимости:

| Тип | Стоимость | Базовый доход | Базовый расход |
| --- | ---: | ---: | ---: |
| Жильё | `250 000` | `45 000` | `12 000` |
| Офис | `400 000` | `70 000` | `22 000` |
| Ритейл | `320 000` | `60 000` | `18 000` |

Улучшение стоит `80 000`, повышает уровень объекта на `1` и увеличивает репутацию на `3`.

## Формулы

Доход объекта:

```text
income = baseIncome * (0.5 + demand / 200) * (0.7 + reputation / 200) * levelMultiplier
```

Множитель уровня:

```text
levelMultiplier = 1 + (level - 1) * 0.15
```

Расход объекта:

```text
expense = baseExpense * (1 + interestRate / 1000)
```

Чистый доход:

```text
netIncome = income - expense
```

Цена продажи:

```text
salePrice = baseCost * (0.72 + demand / 250) * (1 + (level - 1) * 0.08) * holdingMultiplier * 0.92
```

Если объект удерживался меньше 4 кварталов, применяется ранний дисконт `0.86`. Множитель `0.92` отражает комиссию и транзакционные потери при продаже. Это сделано, чтобы нельзя было выигрывать простой схемой "купил-продал".

Кредит:

```text
loanPayment = 300000 * (interestRate / 100) / 8
```

Кредит выдаётся на `300 000`, одновременно может быть только один активный кредит. Срок погашения — 8 квартальных платежей.

## События рынка

После каждого квартала выбирается случайное событие. Оно может менять:

- спрос
- процентную ставку
- репутацию
- деньги

В игре реализовано 14 событий:

- рост интереса к жилью
- спад потребительской активности
- снижение процентной ставки
- рост ставки
- государственная поддержка
- проверка объекта
- удачная PR-кампания
- инфляционное давление
- ремонт инфраструктуры
- рост затрат на обслуживание
- приток бизнеса в район
- сокращение спроса на коммерческие площади
- льготное кредитование
- локальный городской фестиваль

Денежный эффект события масштабируется от размера активного портфеля. Если объектов нет, событие не даёт бесплатные деньги, чтобы нельзя было выиграть простым пропуском ходов.

## Условия завершения

Поражение наступает, если деньги становятся меньше нуля.

Игра завершается на 20 квартале. Для победы должны быть выполнены все условия:

- деньги больше `2 000 000`
- репутация не ниже `60`
- минимум `4` активных объекта
- суммарная прибыль портфеля после платежей не ниже `700 000`
- минимум `2` улучшенных активных объекта
- нет активного кредита

Если к 20 кварталу игрок не проиграл, но не выполнил все условия победы, показывается нейтральный итог.

## Советчик

В игре есть режим подсказок. Это не нейросеть и не внешняя библиотека, а rule-based алгоритм в `script.js`.

Советчик каждый квартал анализирует:

- сколько кварталов осталось
- сколько денег у игрока
- есть ли активный кредит
- сколько объектов построено
- сколько активных объектов улучшено
- хватает ли темпа прибыли до победы
- насколько опасны текущие спрос, ставка и репутация
- какое последнее событие произошло

После анализа советчик предлагает действие: построить объект, улучшить объект, взять кредит, продать лишний актив или пропустить ход. Кнопка "Выполнить совет" использует обычные игровые функции, поэтому советчик не обходит правила игры.

## Карта

Карта рисуется на `canvas` как 2.5D-городская диорама:

- участки расположены на изометрической сетке
- дороги рисуются как связанная дорожная сеть
- здания строятся процедурно как объёмные призмы
- тип здания влияет на внешний вид
- уровень здания влияет на высоту и детализацию
- проданные объекты отображаются отдельно
- машины движутся по заранее заданным дорожным маршрутам

В проекте нет скачанных моделей из интернета. Это важно для простого запуска: все визуальные элементы находятся в коде и не требуют подключения к сети.

## Сохранение

Игра автоматически сохраняет состояние в `LocalStorage` после кварталов и ключевых изменений. Используются:

- автосохранение текущей партии
- восстановление состояния при повторном открытии
- кнопка новой игры
- кнопка сброса прогресса

На стартовом экране нет отдельной кнопки продолжения сохранения, чтобы интерфейс был проще.
