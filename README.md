# Симулятор рынка недвижимости

Веб-приложение на чистом HTML, CSS и JavaScript, моделирующее упрощённый рынок недвижимости.  
Игрок управляет инвестициями в объекты, принимает одно решение за квартал и наблюдает, как меняются капитал, репутация, спрос, процентная ставка и доходность портфеля.

## Что это за приложение

Это одностраничный браузерный симулятор без backend и без внешних зависимостей.  
Приложение запускается простым открытием `index.html` и хранит прогресс в `LocalStorage`.

Игрок:
- строит жильё, офисы и ритейл
- улучшает объекты
- продаёт активы
- при необходимости берёт кредит
- переживает случайные рыночные события
- старается дойти до 20 квартала с сильным капиталом и хорошей репутацией

## Основные возможности

- стартовый экран с описанием игры
- игровой экран с панелью метрик
- управление действиями по кварталам
- карточки объектов недвижимости с текущими расчётами
- система кредита
- случайные события рынка
- история последних событий
- графики динамики денег, спроса и репутации
- автосохранение и загрузка прогресса
- модальное окно победы, поражения или нейтрального итога

## Как работает игровой цикл

За один квартал игрок может выполнить только одно действие:

- построить жильё
- построить офис
- построить ритейл
- улучшить объект
- продать объект
- взять кредит
- пропустить ход

После успешного действия квартал автоматически обрабатывается в таком порядке:

1. Выполняется действие игрока
2. Начисляются доходы и расходы по всем активным объектам
3. Если есть кредит, списывается квартальный платёж
4. Генерируется случайное событие
5. Обновляется состояние рынка
6. Проверяются условия победы или поражения
7. Игра сохраняется в `LocalStorage`
8. Интерфейс полностью перерисовывается

## Игровые параметры

Стартовые значения:

- деньги: `1 000 000`
- репутация: `50`
- спрос: `50`
- ставка: `10`
- квартал: `1`
- суммарная прибыль: `0`
- объектов: `0`
- кредита нет

Типы недвижимости:

### Жильё
- стоимость: `250 000`
- базовый доход: `45 000`
- базовый расход: `12 000`

### Офис
- стоимость: `400 000`
- базовый доход: `70 000`
- базовый расход: `22 000`

### Ритейл
- стоимость: `320 000`
- базовый доход: `60 000`
- базовый расход: `18 000`

Улучшение объекта:

- стоимость улучшения: `80 000`
- уровень объекта увеличивается на `1`
- репутация увеличивается на `3`

## Формулы

Доход объекта:

`income = baseIncome * (0.5 + demand / 200) * (0.7 + reputation / 200) * levelMultiplier`

Где:

- `demand` — текущий спрос
- `reputation` — текущая репутация
- `levelMultiplier = 1 + (level - 1) * 0.15`

Расход объекта:

`expense = baseExpense * (1 + interestRate / 1000)`

Чистый доход:

`netIncome = income - expense`

Цена продажи:

`salePrice = baseCost * (0.8 + demand / 200) * (1 + level * 0.05)`

Кредит:

- сумма кредита: `300 000`
- одновременно можно иметь только один кредит
- после оформления деньги сразу увеличиваются
- каждый квартал платёж считается так:

`loanPayment = 300000 * (interestRate / 100) / 8`

## Репутация, спрос и события

На игру влияют случайные рыночные события. В текущей реализации они меняют общее состояние рынка:

- спрос
- ставку
- репутацию
- деньги

В проекте реализовано более 12 событий, например:

- рост интереса к жилью
- спад потребительской активности
- снижение процентной ставки
- рост ставки
- государственная поддержка
- проверка объекта
- удачная PR-кампания
- инфляционное давление
- ремонт инфраструктуры
- рост затрат на обслуживание
- приток бизнеса
- сокращение спроса на коммерческие площади

После каждого квартала:

- показывается последнее событие
- хранится история последних 5 событий

## Условия завершения игры

### Поражение

Если деньги стали меньше нуля.

### Победа

Если игрок дошёл до 20 квартала и одновременно выполнил условия:

- деньги больше `2 000 000`
- репутация не ниже `60`

### Нейтральный итог

Если игрок дошёл до 20 квартала, но не выполнил условия победы.

После завершения показывается модальное окно с итогом партии и ключевыми показателями.

## Интерфейс

Приложение состоит из нескольких блоков:

### 1. Стартовый экран

- краткое описание проекта
- кнопка новой игры
- кнопка продолжения сохранения
- переход к правилам

### 2. Игровой экран

Содержит:

- верхнюю панель с основными метриками
- левую колонку действий
- центральную колонку карточек объектов
- правую колонку событий и сводки
- нижний блок графиков и истории кварталов

### 3. Модальное окно окончания игры

- победа / поражение / нейтральный итог
- финальные показатели
- кнопка начала новой игры

### 4. Блок правил

Кратко объясняет цель, условия проигрыша, действия за квартал, логику кредита и событий.

### 5. Блок "О проекте"

Описывает учебный характер работы и стек реализации.

## Что важно знать о текущей реализации

- каждый успешный ход сразу завершает квартал
- новый построенный объект начинает участвовать в расчётах в том же квартале
- улучшение объекта влияет на доход сразу
- проданный объект сразу исключается из расчётов
- события влияют на общий рынок, а не на отдельный тип недвижимости
- суммарная прибыль в интерфейсе считается отдельно от полного денежного баланса
