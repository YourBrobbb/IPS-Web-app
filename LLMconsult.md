1. Общая идея проекта

Это учебное веб-приложение, моделирующее упрощённый рынок недвижимости.

Игрок управляет инвестициями в недвижимость и наблюдает, как его решения влияют на:

- репутацию
- рыночный спрос
- процентную ставку
- прибыль

Это не 3D-игра.
Это не карта города.
Это не сложный симулятор с множеством сущностей.

Это простой 2D-сайт-симулятор с панелью управления, карточками объектов и событиями.

2. Формат приложения

Сделай приложение как одностраничный сайт.

Нужны следующие блоки:

3. Модальное окно окончания игры

Все экраны должны быть реализованы внутри одного index.html, без роутинга.

3. Игровая логика

Игрок начинает со следующими параметрами:
- деньги: 1000000
- репутация: 50
- спрос: 50
- ставка: 10
- квартал: 1
- суммарная прибыль: 0

- кредита нет

Есть 3 типа объектов недвижимости:
1. Жильё
2. Офис

Для каждого объекта нужно хранить:

- type

- baseCost

- baseExpense

- status
- createdAtQuarter

status может быть:
- active

Игрок может выполнять только 1 действие за квартал.

Доступные действия:
- построить жильё

- построить ритейл
- улучшить объект
- продать объект
- взять кредит
- пропустить ход

После действия автоматически завершается квартал.

Порядок обработки квартала:
1. Выполнение действия игрока
2. Начисление доходов и расходов по всем активным объектам
3. Учет платежа по кредиту
4. Генерация случайного события
5. Обновление состояния рынка
6. Увеличение номера квартала
7. Сохранение состояния в LocalStorage

4. Формулы

Используй следующие простые формулы:

Доход объекта:
income = baseIncome * (0.5 + demand / 200) * (0.7 + reputation / 200) * levelMultiplier

Где:
- demand = текущий спрос от 0 до 100
- reputation = текущая репутация от 0 до 100
- levelMultiplier = 1 + (level - 1) * 0.15

Расход объекта:
expense = baseExpense * (1 + interestRate / 1000)

Чистый доход:
netIncome = income - expense

Улучшение объекта:
- стоит фиксированную сумму
- повышает level на 1
- повышает репутацию на небольшое значение
- после улучшения объект приносит больше дохода

Цена продажи:
salePrice = baseCost * (0.8 + demand / 200) * (1 + level * 0.05)

Кредит:
- сумма кредита: 300000
- кредит можно иметь только один одновременно
- при взятии кредита деньги увеличиваются на 300000
- затем каждый квартал списывается платеж:
loanPayment = 300000 * (interestRate / 100) / 8

Если кредит уже есть, повторно брать его нельзя.
